Neon Coast — A local browser poster maker for GTA 6 Vice-style movie covers. 100% client-side, no uploads, no Rockstar assets.

Neon Coast is an offline web app that turns a person's photo and caption into GTA 6 poster-style multi-panel cover art: 4 layouts (Vice Trio, Sunset Grid, Widescreen Strip, Solo Poster), 4 colour schemes (Sunset, Neon Nights, Noir, Palm Gold), 3 title styles (Bold block, Outline, Neon glow), and export sizes 1080x1080, 1080x1350 and 1920x1080 — drag each panel's photo into place with per-panel zoom, style the bold caption lettering, and export a PNG, all in the browser, with no network requests and no Rockstar logo, artwork or font.

All processing runs in your browser, images never leave your device. Original branding Neon Coast, no copyrighted GTA artwork bundled.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 (or serve `app/` with any static server, e.g. `python3 -m http.server` from inside `app/`). Add your own photos, choose a layout and grade, drag each panel's photo into place, and hit an export button to download the PNG.
